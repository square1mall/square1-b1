V42 업데이트 안내

이번 버전은 이벤트 자동 슬라이드의 반복 구간 계산을 보완했습니다.

- 마지막 이벤트 다음에 첫 번째 이벤트가 자연스럽게 이어지도록 무한 반복
- 슬라이드 위치 계산을 실제 카드 위치 기준으로 변경해 끝에서 멈추는 현상 방지
- PC 자동 이동 속도, 마우스 오버 일시정지/재개, 좌우 화살표 기능 유지
- 모바일은 기존처럼 자동 이동 없이 터치 스와이프 방식 유지
- 기존 이벤트 내용과 노출 날짜는 변경하지 않았습니다.

GitHub 업데이트 방법
1. 압축을 풀고 기존 저장소 파일에 덮어쓰기
2. GitHub에서 변경된 파일을 업로드/교체
3. Commit changes 후 홈페이지 새로고침
