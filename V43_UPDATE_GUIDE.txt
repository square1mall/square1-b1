V43 코드 정리본 안내

이번 파일은 기존 V43_LOOP_FIXED 프로젝트를 기준으로, 관리자가 수정하는 설정 코드의 위치를 실제 홈페이지 화면 위→아래 순서에 맞춰 정리한 버전입니다.

[events.js 관리영역 순서]
01. MAIN — 메인 비주얼 이미지/영상, PC·모바일 문구 및 위치
02. NOW AT B1 — 문구와 카테고리 링크는 index.html에서 수정
03. EVENT & PROMOTION — 마케팅 이벤트를 모아 관리
04. BRAND EVENT — 브랜드 이벤트를 모아 관리
05. B1 BRAND — 브랜드 로고 이미지와 이름
06. B1 FLOOR GUIDE — 안내 문구는 index.html, 도면 이미지는 images 폴더에서 관리
07. MORE SQUARE1 — 하단 홈페이지/인스타그램/카카오톡 링크

[이벤트 관리]
- 이벤트 항목은 마케팅 이벤트를 먼저, 브랜드 이벤트를 다음에 모아두었습니다.
- 각 이벤트의 order 값은 해당 이벤트 구역 안에서 표시되는 순서를 결정합니다.
- 카드 내용은 title / dateText / thumb, 상세 이미지는 detailImage, 상세 본문은 content / info에서 수정합니다.
- 노출 상태는 mode(auto/on/off), 노출 기간은 startDate / startTime / endDate / endTime에서 수정합니다.

[주의]
- 관리영역 아래쪽의 FUNCTION 코드는 화면 출력과 슬라이드 동작을 담당합니다. 일반적인 문구·이미지·기간 수정 시에는 수정하지 않는 것을 권장합니다.
- 이번 정리는 코드 배치와 주석을 정돈한 작업입니다. 기존 디자인, 이벤트 내용, 파일 경로 및 슬라이드 동작 코드는 불필요하게 변경하지 않았습니다.
- 홈페이지 업로드 시 기존 프로젝트 파일을 백업한 뒤, 압축을 푼 폴더 안의 파일 전체를 기존 저장소에 반영해 주세요.
