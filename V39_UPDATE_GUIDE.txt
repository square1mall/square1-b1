THE GREAT SQUARE1 B1 — V39 업데이트 안내

[01] 메인 문구 PC·모바일 분리 관리
events.js의 HERO_TEXT에서 pc / mobile 항목을 각각 수정합니다.
- title: THE GREAT SQUARE1 문구
- copyLines: 한 줄씩 입력하며 배열 항목마다 줄바꿈됩니다.
- titleFontSize / copyFontSize: 글자 크기
- titleFontWeight / copyFontWeight: 글자 굵기
- titleColor / copyColor: 글자 색상
- titleX / titleY, copyX / copyY: 각 문구 위치
- contentLeft / contentBottom: 문구 묶음의 좌우·아래 여백
PC와 모바일은 서로 독립적으로 수정할 수 있습니다.

[02] FLOOR MAP PC·모바일 이미지
- PC: images/floor-map-pc.jpg
- 모바일: images/floor-map-mobile.jpg
화면 너비 767px 기준으로 자동 전환하며, 이미지 원본 비율을 유지해 전체가 보입니다.

[03] 메인 이미지·영상 슬라이더 관리
events.js의 HERO_SLIDES 배열에서 순서대로 관리합니다.
- type: image 또는 video
- image: pc / mobile에 PC·모바일 JPG 경로 지정, duration은 노출 시간(초)
- video: pc / mobile에 PC·모바일 MP4 경로 지정
- pcFallback / mobileFallback: 영상 재생 실패 시 표시할 대체 이미지
- start / end: 영상 시작·종료 구간(초). end를 빈 값으로 두면 영상 종료 시 다음 슬라이드로 이동
배열 항목을 복사해 추가하고, 항목 순서를 바꾸면 화면 재생 순서도 바뀝니다.
PC·모바일 파일 경로를 각각 지정할 수 있습니다.

[04] 유지되는 기존 기능
- 이벤트 슬라이더 및 PC 좌우 화살표·마우스 드래그·자동 이동
- 모바일 이벤트 스와이프
- 브랜드 로고 슬라이더(한 번에 1개씩 이동)
- 이벤트 전체 목록 및 상세페이지·상세 동영상
- events.js 이벤트 관리 영역 및 하단 바로가기 링크
