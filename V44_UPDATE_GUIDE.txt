THE GREAT SQUARE1 B1 — V44 UPDATE GUIDE

기준 파일: V43_CODE_ORDERED
V44 추가 기능:
1. 메인 이미지 슬로우 줌
   - 이미지 슬라이드가 활성화될 때 약 6초 동안 100%에서 106.5%까지 천천히 확대됩니다.
   - 영상 슬라이드에는 줌 효과를 적용하지 않습니다.
2. 이미지 크로스페이드
   - 이미지/영상 슬라이드 전환이 약 1.15초 동안 부드럽게 진행됩니다.
3. 메인 문구 등장 효과
   - 기존 문구의 내용과 배치는 유지하고, 슬라이드가 바뀔 때 메인 문구 묶음이 살짝 위로 이동하며 페이드 인됩니다.
4. 우측 상단 정보 위젯
   - 영업시간: 10:30~22:00 기준 OPEN/CLOSED 표시
   - 날씨: 인천 연수구 동춘동 중심 좌표 기준
   - Open-Meteo 공개 API 사용, API 키 불필요
   - 날씨는 30분마다 갱신, 영업 상태는 1분마다 갱신
   - 대표전화는 표시하지 않습니다.
5. 포인트센터 / 사은행사장 이전 안내
   - B1 FLOOR GUIDE 바로 아래에 추가했습니다.
   - 좌측: 이전 안내, 운영시간, 위치(OO 옆), 이용 가능 서비스
   - 우측: 기존 B1 FLOOR GUIDE 도면 이미지 재사용
   - 위치 문구는 index.html에서 'OO 옆'을 실제 위치로 변경하면 됩니다.

수정 위치:
- 메인 영업시간 / 날씨 위젯 마크업: index.html의 hero-info-widget
- 포인트센터 / 사은행사장 문구: index.html의 service-center-section
- 디자인 및 반응형: style.css 맨 아래 V44 UPDATE 구역
- 날씨 API / OPEN-CLOSED 처리: events.js의 initHeroInfoWidget()
- 기존 이벤트 / 브랜드 / 슬라이드 관리 영역은 그대로 유지했습니다.

참고:
- OPEN/CLOSED는 한국 시간 기준 10:30~22:00으로 계산합니다. 임시 휴점 등 별도 휴무일은 자동 반영하지 않습니다.
- 날씨 데이터는 외부 Open-Meteo 서비스와 인터넷 연결이 필요합니다.
- B1 도면에는 정확한 서비스센터 위치가 아직 확인되지 않아 별도 핀을 임의로 표시하지 않았습니다.
