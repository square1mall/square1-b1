THE GREAT SQUARE1 B1 — V38 업데이트 안내

1. 메인 우측의 기능이 없는 삼선 메뉴 아이콘을 삭제했습니다.
2. images/logo.png를 사용자가 전달한 새 로고 이미지로 교체했습니다.
3. images/main-video-pc.mp4를 사용자가 전달한 새 가로형 PC 영상으로 교체했습니다.
4. events.js 상단에 홈페이지 화면 순서 기준의 빠른 목차를 추가했습니다.
   MAIN → NOW AT B1 → EVENT & PROMOTION → BRAND EVENT → B1 BRAND
   → B1 FLOOR GUIDE → MORE SQUARE1
5. 마케팅 이벤트와 브랜드 이벤트는 동일한 이벤트 캐러셀 렌더링 함수를 사용합니다.
   PC: 이전/다음 화살표, 마우스 드래그, 자동 슬라이드, 마우스 오버 시 일시정지
   모바일: 손가락 스와이프, 자동 슬라이드/화살표 숨김
6. PC 화살표는 두 이벤트 영역 모두 표시됩니다. 현재 노출 이벤트가 1개뿐이면 이동할 수 없어 화살표가 비활성화되고, 2개 이상이면 이전/다음 이동이 가능합니다.
